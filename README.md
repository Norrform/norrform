# Norrform

Static responsive portfolio for a Swedish small-business web design service.

## Included
- Agency landing page
- Two fictional demo concepts: Fjällglans (cleaning) and Norrverk (construction)
- Mobile responsive layouts
- No dependencies, forms, analytics, or data collection

## Important before launch
- Replace hej@norrform.se with an inbox actually controlled by Norrform.
- Demo brands are fictional and clearly labelled as concepts, not client work.
- Confirm business registration, contracts, tax, and payment arrangements with a parent/guardian before taking paid work.
- Check all contact and legal details before publishing.
